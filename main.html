LoRGen: Two-Stage LLM Framework for Human-Aligned Letter of Recommendation Generation

  • Improved personalization, tone consistency, and contextual coherence through preference-based optimization.
  • Published as Top 2% Paper at ICCIT 2025.
LLM DPO PEFT Fine-Tuning

Enhancing Genre Fidelity in Children's Story Generation via Fine-Tuned LLMs
  • Designed a genre-conditioned story generation framework using LLaMA-2 (7B) fine-tuned with PEFT-LoRA.
  • Evaluated genre adherence using a transformer-based classifier.
  • Developed evaluation workflows for genre classification and response quality analysis.
LLaMA-2 LoRA NLP
